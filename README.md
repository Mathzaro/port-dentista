# 🦷 Dra. Helena Prado · Odontologia

Site de apresentação de um consultório odontológico **fictício**, feito com **HTML e CSS puros**, sem frameworks.

Projeto de portfólio para praticar HTML semântico, CSS responsivo (mobile first) e acessibilidade.

## ✨ O que já tem

- Layout responsivo pensado primeiro para celular, com ajustes para tablet e desktop via `media queries`
- HTML semântico: `header`, `nav`, `main`, `section`, `address`, `blockquote`, lista de definições (`dl`) para os tratamentos e tabela com `caption` e `th scope` para os horários
- Ilustração do sorriso feita em **SVG próprio**, com uma animação leve que respeita a preferência do sistema por menos movimento (`prefers-reduced-motion`)
- Acessibilidade: link "Pular para o conteúdo", foco visível para navegação pelo teclado, `aria-label` e `aria-labelledby`
- Variáveis CSS (`:root`) para cores, tipografia e espaçamentos
- Tipografia: Bricolage Grotesque nos títulos e Atkinson Hyperlegible no texto (fonte criada para facilitar a leitura)

## 🚀 Como ver

Baixe ou clone o repositório e abra o `index.html` no navegador. Não precisa instalar nada.

```bash
git clone https://github.com/Mathzaro/port-dentista.git
```
